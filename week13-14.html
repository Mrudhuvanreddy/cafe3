LAB VIVA QUICK REVISION - WEEKS 13 & 14: Q1: What are Angular Forms, and what types are available? A: Angular provides two approaches for handling user input through forms: 1. Template-Driven Forms: Simple, logic defined in template with [(ngModel)] and directives. 2. Reactive (Model-Driven) Forms: More scalable, defined in component class using FormGroup and FormControl. Q2: What do form control states ($valid, $invalid, $touched, $dirty, $pristine) mean? A: - valid / invalid: Indicates whether all validation rules (required, minlength, email) pass. - touched / untouched: Indicates whether the user has focused and left the field. - dirty / pristine: Indicates whether the field value has been modified by the user. Q3: What is Angular Routing and what is <router-outlet>? A: Angular Routing enables navigation between views in a Single-Page Application (SPA) without reloading the full page. <router-outlet> acts as a placeholder directive that Angular dynamically fills based on the current router state. Q4: What is an Angular Service and why use Dependency Injection (DI)? A: An Angular Service is a class with @Injectable() that encapsulates business logic, data access, and cross-component communication. Dependency Injection provides singleton instances of services to components without manual instantiation, promoting modularity, reusability, and clean architecture.
