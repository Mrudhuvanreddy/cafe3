LAB VIVA QUICK REVISION - WEEK 12: Q1: What is an Angular Component? A: A fundamental building block of Angular UI. Consists of a TypeScript class for logic, an HTML template for the view, and CSS for styles, declared with the @Component decorator. Q2: What is the difference between One-Way and Two-Way data binding? A: - One-Way Data Binding flows in one direction: * Component to View: Interpolation {{ '{{ }}' }} and Property Binding [property]. * View to Component: Event Binding (event). - Two-Way Data Binding: Synchronizes both View and Component simultaneously using [(ngModel)]. Q3: What are Directives in Angular? A: Directives are classes that add additional behavior to elements in the template: - Structural Directives (*ngIf, *ngFor, *ngSwitch): Change DOM structure by adding/removing elements. - Attribute Directives ([ngClass], [ngStyle]): Change appearance or behavior of existing elements.
