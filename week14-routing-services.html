LAB VIVA QUICK REVISION - WEEK 14: Q1: What is a Single-Page Application (SPA)? A: An SPA is a web application that loads a single HTML page and dynamically updates content as the user interacts with the app, without requiring full page refreshes from the server. Q2: What is Angular Routing and what is <router-outlet>? A: Angular Routing manages navigation between different components based on browser URL changes. <router-outlet> is a directive that acts as a placeholder where Angular renders the currently matched route's component. Q3: What is Dependency Injection (DI) in Angular? A: Dependency Injection is a design pattern in which a class receives its dependencies (such as services) from an external provider rather than creating them itself. Q4: What does @Injectable({ providedIn: 'root' }) mean? A: It registers the service as a singleton provider at the root level of the application, meaning a single shared instance is used across all components.
